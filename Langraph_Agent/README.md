# Langraph Agent Codebase

This project implements an agent using Langraph and an LLM to extract keywords from user input, retrieve similar items from the Web_scraper database, and output matches.

## Features
- Accepts a sentence containing keywords
- Uses LLM to extract keywords
- Retrieves similar items from the Web_scraper database
- Outputs mapping of input keywords to matched items

## Usage
- See `main.py` for entry point
- Ensure `Web_scraper` is available in the workspace
